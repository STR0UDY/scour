Scour

The Windows cleaner CCleaner used to be, minus the bloat. It frees disk space, shows where the space went and tidies startup, and it never deletes anything you haven't seen first.

Download for Windows Source on GitHub

or winget install Scour.Scour

Clean

Temp files, update caches, crash dumps, logs, GPU shader caches, browser and app caches, and the Recycle Bin. Every item shows exactly which files it would remove.

Analyse

A treemap of any drive, read straight from the NTFS file table in seconds. Drill in, sort, break it down by file type.

Startup

Apps, scheduled tasks and services that start with Windows, with verified publishers. Switch them off reversibly, the way Task Manager does.

Apps

Uninstall with the app's own uninstaller, then see what it left behind before anything is removed.

Boring, on purpose

  • Preview before delete. No blind one-click wipe. You see paths and sizes first.
  • Nothing hidden. No telemetry, no ads, no account, no background service. Update checks are opt-in.
  • Rules are data. Every cleanable location is a small JSON file anyone can read, audit and improve.
  • Safe by default. Cookies, history, sessions and the Recycle Bin stay off until you tick them. System folders and your documents are on a deny-list no rule can override.
  • Least privilege. Scour runs as you. A tiny helper asks for admin only when you tick something that needs it.

What it won't do

No registry cleaner, no RAM "optimiser", no driver updater, no "PC health" score. They don't make Windows measurably faster, and some of them break it.
